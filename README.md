## ✨ Features

- **Digital Aurora Identity:** Deep midnight charcoal and plum palette with aurora violet, electric cyan, and mint accents.
- **3D WebGL Aurora Orb:** Interactive translucent icosahedron with custom vertex displacement shaders, particle cloud, and orbiting light rings powered by Three.js.
- **Custom Cursor:** Dual-layer lerp tracking glowing cursor with magnetic button attraction and dynamic "VIEW" card badges.
- **Technology Constellation:** Interactive technology constellation with dynamic SVG connector lines and holographic HUD details.
- **Cinematic Project Cards:** Showcase case studies with 3D tilt effects, parallax depth, and architectural metadata.
- **Digital Lab:** Futuristic experimental interface featuring telemetry and status analysis across systems.
- **Animated Journey Timeline:** Sequential glow-activated milestone track.
- **Direct Contact System:** Integrated email, WhatsApp, and GitHub gateways.
